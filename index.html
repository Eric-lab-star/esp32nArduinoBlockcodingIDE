          시작 가이드
          
        

        

          
    
            
  1. 
              MicroPython 펌웨어 설치 (보드당 1회)
    
              피코의 BOOTSEL 버튼을 누른 채 USB를 연결하면 RPI-RP2 드라이브가 나타납니다.
              MicroPython UF2 파일 ↗을
              드라이브에 복사하면 자동으로 재부팅됩니다. (피코 W / 피코 2는 각 보드 전용 UF2 사용)
            
    2. 
            
  2. 
              보드 연결
    
              상단의 보드 연결 버튼을 누르고 목록에서 피코의 시리얼 포트를 선택합니다.
              다른 프로그램(Thonny 등)이 포트를 사용 중이면 먼저 종료하세요.
            
    3. 
            
  3. 
              코딩하고 실행
    
              블록을 조립하거나 파이썬 코드를 작성한 뒤 실행(Ctrl+Enter)을 누르세요.
              main.py 저장을 누르면 보드 전원을 켤 때마다 자동으로 실행됩니다.
            
    4.
